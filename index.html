🚀 Method 1: Cloudflare Worker (1-Minute Setup)

Cloudflare Workers 100% free hai aur kabhi sleep nahi hota (100,000 requests/day free):

  1. Open workers.cloudflare.com and sign in.
  2. Click Create Application → Create Worker.
  3. Click Deploy, then Edit code.
  4. Paste the ready-made code below and click Deploy.
  5. Copy your Worker URL (e.g. https://my-bot.workers.dev), paste in the box on the left, and click Set 24/7 Webhook!
cloudflare_worker.js (Ready to Deploy)

📦 Method 2: Node.js 24/7 Background Server (Render.com / Koyeb / VPS)

This repository already includes server.js, package.json, and Procfile ready for 24/7 hosting:

1 Deploy to Render.com (Free 24/7)

Go to render.com → New Web Service → Connect your GitHub Repo → Select Environment: Node → Start Command: node server.js. Render will run the bot in the cloud 24/7 without needing your browser!

2 Run Locally or on VPS / Termux

Run node server.js in Termux or any Linux VPS. It will poll Telegram continuously in the background and respond instantly!

🚀 How to Host on GitHub Pages (Free 24/7)

You can host this entire web interface directly from GitHub with zero server cost:

  1. Create a GitHub Repo: Go to github.com/new and create a public repository (e.g. bothost-web).
  2. Push these files: Upload index.html, style.css, and app.js to the repository.
  3. Enable GitHub Pages: Go to Repo Settings → Pages → Source: Deploy from a branch → Select 'main' / root → Save.
  4. Done! Your live website URL will be https://<username>.github.io/<repo>/ running 24/7!
💡 Direct Bot API: The website communicates directly with Telegram Bot API via HTTPS client-side requests, meaning it runs 24/7 on GitHub Pages without requiring paid backend servers!
